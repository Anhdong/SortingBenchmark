## Sorting Benchmark using Java

# Project Objective
Design a Java-based benchmarking tool to determine the optimal subarray size (cutout size) 
when Quick Sort and Merge Sort should switch to Insertion Sort for maximum CPU cache efficiency, 
visualize the results using Python.
